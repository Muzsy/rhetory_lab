# Moderáció minimum spec

## 1. Cél
Az MVP-ben nem teljes policy-rendszer kell, hanem működő minimum védelem.

## 2. Minimum elvek
Nem megengedett:
- gyűlöletkeltő tartalom
- zaklató, súlyosan sértő tartalom
- nyílt fenyegetés vagy erőszakos tartalom
- spam
- rendszeridegen, szándékosan romboló tartalom

## 3. Felhasználói eszköz
### Report
A user jelenthet:
- submissiont
- scenario-t (ha szükséges)
- később esetleg profilt

MVP-ben elég egy egyszerű report flow:
- jelentés indítása
- rövid indok
- elküldés

## 4. Admin eszközök
Az admin képes legyen:
- report megtekintésére
- submission elrejtésére
- submission removed státuszra állítására
- scenario rejtésére / archiválására
- extrém esetben user tiltására

## 5. Minimum folyamat
1. user reportot küld
2. report open státuszban bekerül
3. admin átnézi
4. admin actiont hoz
5. report reviewed / closed állapotba kerül

## 6. Mi nincs az MVP-ben
- automatizált AI moderáció
- bonyolult strike rendszer
- appeal workflow
- részletes policy könyvtár
