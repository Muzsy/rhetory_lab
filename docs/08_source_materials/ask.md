# Az alkalmazás elkészítéséhez szükséges információk
A dokumentáció alapján az alábbi területeken van szükség döntésekre:

## 1. Technológiai alapok
Kérdés Miért fontos Mobilstack – Flutter, React Native, vagy más? A fájlstruktúra Flutter monorepo-t feltételez Backend – Firebase, Supabase, egyedi API (Node/Go/etc.)? Meghatározza az architektúrát Database – Firestore, PostgreSQL, más? Adatmodell tervezéséhez kell Design rendszer – Figma projektek, design token-ek? UI kit építéséhez szükséges

## 2. MVP scope pontosítása
A koncepciovazlat 4 fázist javasol. Melyikkel indulunk?

MVP 1 (minimum):

- Regisztráció és profil
- Szituációlista + részletes nézet
- Reakció beküldés
- Egyszerű szavazás
- Napi/heti toplista
- Admin felület szituációk létrehozására
## 3. Szituációkészítés
- Kik írják a szituációkat? Admin kézi, AI-asszisztált, közösségi?
- Mennyi induló tartalom kell? 10, 50, 100 szituáció?
- Milyen témák domináljanak? Fiktív, anonimizált, vagy valós esetek?
## 4. Értékelési rendszer
A lehetseges_problemak hangsúlyozza a pontozás torzulásának veszélyét.

Döntendő:

- Egyszerű like/upvote vagy többtényezős pontozás?
- Teljesen vak értékelés (név nélkül) vagy látható szerző?
- Értékelők súlyozása (reputáció alapján)?
## 5. Design & identitás
- Hangulat: Komoly/professzionális, játékos/lazább, vagy vegyes?
- Vizuális stílus: Milyen színpaletta, tipográfia, ikonstílus?
- Fő fókusz: Retorika, PR/válságkezelés, vagy általános meggyőzés?
## 6. Jogi/etikai keretek
- Moderációs szabályok konkrét megfogalmazása
- Tiltott tartalom pontos definíciója
- Valós személyekre vonatkozó korlátozások
- Adatkezelési és GDPR szempontok
## 7. Indulási stratégia
- Platform: iOS először, Android először, vagy mindkettő egyszerre?
- Tesztelés: Zárt bétateszt, vagy nyílt indulás?
- Monetizáció: Induláskor ingyenes, később prémium funkciók?
## Összefoglalva
Az 5 legkritikusabb döntés az induláshoz:

1. ✅ Tech stack (mobil framework + backend)
2. ✅ MVP funkciók pontos listája
3. ✅ Értékelési mód (simple vs. komplex)
4. ✅ Design irány (hangulat, vizuális identitás)
5. ✅ Első 20-50 szituáció tartalma és témái
