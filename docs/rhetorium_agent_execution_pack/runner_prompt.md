# Runner Prompt

Használd a mellékelt dokumentumokat a Rhetorium MVP önálló kivitelezésére.

Kötelező olvasási sorrend:
1. `frozen_product_decisions.md`
2. `agent_master_prompt.md`
3. `goal.yaml`
4. `definition_of_done.md`
5. `execution_notes.md`

Feladat:
- Építsd meg a működő MVP-t a dokumentumban rögzített scope szerint.
- Dolgozz vertikális szeletekben.
- Minden task után verify-olj.
- Ne bővítsd a scope-ot.
- Ne találj ki új feature-t.
- Ha döntési bizonytalanság van, válaszd a kisebb, egyszerűbb, MVP-kompatibilis megoldást.

Kimenet minden milestone után:
- mi készült el
- milyen fájlokat érintettél
- hogyan ellenőrizted
- mi a következő lépés
