## Megjegyzés
A csomag a lezárt MVP-döntésekre épül:

- Flutter monorepo + Supabase
- Android first
- zárt béta
- teljesen ingyenes indulás
- MVP-ben admin által létrehozott szituációk
- reakcióbeküldés + reakcióolvasás + egyszerű like/unlike
- intelligens, letisztult, enyhén kompetitív hangulat

Ahol még nem volt teljesen lezárt technikai döntés, ott a dokumentumok használható alapfeltevéseket rögzítenek. Ezeket a `99_Assumptions_and_open_points.md` foglalja össze.
