# Design system minimum

## 1. Hangulat
- intelligens
- letisztult
- enyhén kompetitív
- kulturált
- nem harsány

## 2. Alapelemek
- primary color
- secondary / accent color
- neutrals
- error / success / warning színek
- alap typography scale
- spacing scale
- radius rendszer
- elevation / surface szintek

## 3. Kötelező UI elemek
- primary button
- secondary button
- text field
- card
- app bar
- list item
- modal / bottom sheet
- empty state
- loading state
- error state
- badge / small count pill
- like button

## 4. Szövegkezelés
- brief és reaction olvashatóság elsődleges
- jó soremelés
- nem túl szűk tördelés
- kontrasztos, kényelmes olvasás

## 5. Ikonhasználat
- kevés, funkcionális ikon
- ne legyen túl játékos
- admin és report akciók jól elkülönüljenek

## 6. Komponens-prioritás
A design rendszer fókusza az MVP-ben:
- scenario card
- scenario header
- submission editor
- submission card
- like interaction
- auth formok

## 7. Ami ráér későbbre
- komplex motion rendszer
- bonyolult badge vizualitás
- klubidentitás vizuális elemei
- szezonális branding
